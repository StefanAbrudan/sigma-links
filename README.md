# Sigma Bali links

The link page for the Sigma Bali Instagram profile, served at links.sigmabali.com.

## Curtain intro

The opening matches the main site's black silk curtain gathering into a triangular opening before lifting away, followed by the Sigma logo moving into the header. The links version uses a 28 KB JPEG and inline CSS/JavaScript, without video, WebGPU or external animation dependencies. It completes in 1.8 seconds and plays once per session. `?intro` replays it; `?nointro` bypasses it. Reduced motion bypasses the animation, Skip ends it immediately, and all links remain available with JavaScript disabled.

Checked in Chrome at mobile and desktop sizes, including repeat visits, Skip, reduced motion and JavaScript disabled. Deployment is GitHub Pages from `main`.
